Server function check

Tests the three PSI LMS server functions on your Supabase project, from your browser.

Your password is sent only to your own Supabase project, to the login function. It is not stored anywhere. The check creates one test student.

When you are done
  1. In Supabase, open Authentication → Users, find the test student (lmstest) and delete it.
  2. In your GitHub repository, delete this page (function-test.html) so it is no longer on the public site.
